# 몽피스 테니스 — 리그 종류 · 규칙 · 포인트 계산 (앱에 적용된 로직)

> 이 문서는 앱 코드에 **실제 구현되어 동작하는** 규칙을 그대로 정리한 것입니다.
> (근거: `src/utils/tennis/` 의 `rankPoints.js`, `leagueDerivation.js`, `tennisStandings.js`, `tennisSchema.js`)
> 마지막 반영: 2026-08-13 배포분.

---

## 1. 리그 종류

| 리그 | 경기 방식 | 순위 기준 | 집계 단위 |
|------|-----------|-----------|-----------|
| **투몽리그** | 복식(2:2) | **승률** | 연도별 |
| **길로틴리그** | 단식(1:1) | **포인트** | 연도별 |
| (미반영) | 용병전·연습 등 | 전적 미집계 | — |

- **두 리그 모두 연도 단위**로 집계합니다(매년 새로 시작). 앱의 **리그 탭**에서 연도를 골라 볼 수 있습니다.
- 대시보드의 "단식 포인트 TOP5"는 **통산 누적**(연도 무관 스냅샷)이며, 정식 연도별 순위는 리그 탭이 기준입니다.

---

## 2. 회원 등급 체계

회원명부에 저장되는 4개 등급(약함 → 강함):

**초보자 < 동배 < 은배 < 금배**

- 등급은 포인트의 "등급 업셋" 판정(§4)에 쓰입니다.
- 용병(명부에 없는 참가자)은 등급이 없어 등급 관련 가산이 적용되지 않습니다.

---

## 3. 투몽리그(복식) 순위 규칙

- **승률순**으로 순위를 매깁니다. 승률 = 승 ÷ (승 + 패).
- 동률이면 **승수 → 이름(가나다)** 순으로 정렬합니다.
- 각 회원의 등급을 함께 표시합니다.
- **복식에는 포인트가 없습니다.** 순수 승률 순위입니다.

---

## 4. 길로틴리그(단식) 순위 규칙

### 4-1. 순위는 "포인트순"
- **포인트 합계 내림차순**으로 순위를 매깁니다.
- 동점이면 **승률 → 승수 → 이름(가나다)** 순으로 정렬합니다.

### 4-2. 흑기사 / 흑장미 두 그룹으로 나뉨
포인트 계산의 기준이 되는 그룹 분할입니다.

- **매 경기일마다**, 그 **경기일 직전까지 누적된 단식 승률**로 회원을 줄 세웁니다.
  - 상위 절반 = **흑기사**, 하위 절반 = **흑장미**.
  - 인원이 홀수면 **흑기사(상위)를 더 적게**, 흑장미(하위)를 더 많게 나눕니다.
- **당일 경기 결과는 그날의 그룹 판정에 넣지 않습니다.** → 하루 안에서는 그룹이 고정되고, 마감(입력) 순서가 바뀌어도 포인트가 흔들리지 않습니다.
- 시즌 초처럼 **가를 근거가 전혀 없으면 전원 흑기사**로 둡니다(중립 — 아래 "장미가 기사를 이김" 보너스가 발생하지 않음).
- (선택) **시즌시작순위**를 입력해 두면 시즌 초 그룹 분할의 기준으로 씁니다. *현재는 미입력 상태입니다.*

---

## 5. 포인트 계산 방식 (단식/길로틴 전용)

**이긴 선수**에게 아래 조건을 **합산**합니다. (진 선수는 0점)

| 조건 | 가산 |
|------|:----:|
| 기본 승리 | **+1** |
| **같은 리그**에서 승률이 더 낮은 쪽이 이김 (같은 그룹 내 이변) | **+2** |
| **흑장미(하위 그룹)가 흑기사(상위 그룹)를 이김** | **+3** |
| **하위 등급이 상위 등급을 이김** (예: 동배가 은배·금배를 이김) | **+5** |

**규칙 상세**
- **+2 와 +3 은 상호 배타적**입니다.
  - 두 선수가 **같은 그룹**이면 → 승률 이변(+2) 경로만 검토.
  - 두 선수가 **다른 그룹**이면 → 흑장미가 이겼을 때만 +3 (흑기사가 흑장미를 이기면 이변 아님 → 보너스 없음).
- **최대 점수 = 1 + 3 + 5 = 9점** (한 경기).
- 승률·그룹(흑기사/흑장미) 판정은 모두 **"경기일 직전값"** 을 씁니다(§4-2와 동일 원칙).
- 용병(명부 밖)은 등급이 없어 **등급 업셋(+5)이 적용되지 않습니다.**

**예시**
- 동배 A(흑장미)가 은배 B(흑기사)를 이김 → 1(기본) + 3(장미가 기사를) + 5(하위 등급이 상위를) = **9점**
- 같은 흑기사 그룹의 승률 30% C가 승률 70% D를 이김(동일 등급) → 1 + 2(같은 리그 이변) = **3점**
- 흑기사 상위 E가 흑장미 하위 F를 이김(동일 등급) → 1(기본만) = **1점**

## 6. 의뢰인(몽피스) 확인이 필요한 항목

아래는 현재 앱에 적용된 기본값이며, 클럽 규정과 다르면 조정할 수 있습니다.

1. **등급 2단계 이상 차이의 점수** — 현재 **차이와 무관하게 고정 +5**입니다(예: 동배가 금배를 이겨도 +5). "단계당 가산(예: 2단계면 +10)"으로 바꾸려면 옵션(`gradeUpsetPerStep`)만 켜면 됩니다.
2. **흑기사/흑장미 분할 기준** — 현재 **"누적 승률(경기일 직전)"** 기준입니다. 클럽 규정이 "월별 전적" 기준이라면 로직 조정이 필요합니다.
3. **시즌시작순위 입력** — 입력해 두면 시즌 초 그룹 분할이 더 정확해집니다(현재 미입력이라 시즌 초엔 전원 흑기사에서 출발).
