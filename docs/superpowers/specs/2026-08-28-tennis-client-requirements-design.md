1. **티어 배정 기준은 승률 유지**(순위표 표시만 승수순). 티어는 포인트 +3 판정에 쓰여 승수 기준으로 바꾸면 과거 포인트가 재계산되므로 보류.
2. **투어리그 정원 상위 8명 고정**(`TOUR_SLOTS = 8`). 8명 이하면 전원 투어. 이전 "회원 수의 절반"에서 변경.
3. 대시보드 타일 '이달 승률 1위' → **'이달 다승 1위'**(승수↓→승률↓, 3경기↑).

## 정정 (2026-08-28 오후, 유저 결정)

**길로틴리그(단식) 순위는 기존 방식 유지: 승률↓ → 승수↓ → 이름.** 순위에 연동된 포인트·티어 제도가 있어 승수 우선 원칙의 **예외**로 둔다. 적용처: 리그 탭 길로틴 순위표, 대시보드 단식 TOP5, 2024/2025 단식 연도 순위(`buildLegacyStandings` 단식 분기). `buildSinglesStandings` 기본 `sortBy:'rate'`, 포인트 모드 동점도 승률→승수. 복식·페어·파트너·상대전적·선수 성적표·이달 다승 1위는 승수 우선 그대로. 순위표 각주를 "# = 승률순" 으로 수정.

## 최종 확정 (2026-08-28 저녁, 유저)

**단식·복식 리그 순위 기준 = 승률 ↓ → 승수 ↓ (이름 제외).** 동률은 명부 순서 유지(안정 정렬, 이름으로 가르지 않음). 적용: 리그 탭 길로틴·투몽 순위표, 2024/2025 연도 순위, 대시보드 단식/복식 TOP5(`buildSinglesStandings` 'rate'·`buildDoublesStandings` `byRateWins`·`buildLegacyStandings`). 각 순위표 제목 아래 "순위 기준" 문구 표시. **승수 우선은 지표 표(선수 성적표·복식 페어 전적·파트너별·상대전적·이달 다승 1위)에만** 남는다. 베이글 용어: 준/먹음 → 베이글 Maker/Eater.
